## The 12 same-defect reposts that remain

Every one fails the text bar (Jaccard 0.02 to 0.17) and matches through a shared `symbol` subject,
the function or component both findings sit in, with different second subjects. The publisher's key
needs the exact subject set, so it keeps them apart. PR letters replace repository and number; the
log names the real pairs and stays outside the repo.

1. A: import skips an internal-only validator, versus a re-key path hard-deleting an enabled row. Distinct.
2. B: auto-unmute rewrites the persisted mute preference, versus unmute repeating on every reconnect. Distinct.
3. C: duplicate-membership guard race, versus a provisioning error escaping as an HTML 500. Distinct.
4. C: only a lock error caught around the critical section, versus a bare plan code sent to billing. Distinct.
5. C: wrong price charged under a settings toggle, versus a KeyError on an unknown token value. Distinct.
6. C: cost validation mutating the submitted value, versus the HTML 500 of pair 3. Distinct.
7. C: request-scoped toggle API misuse, versus the self-join refusal check. Distinct.
8. C: toggle evaluated for the host instead of the viewer, versus the self-join refusal of pair 7. Distinct.
9. D: live query not gated on availability, round 1 and round 2 at the same line. A restatement the
   publisher misses: Jaccard 0.14 and the second subject differs. Left as is per the decision log.
10. E: toggle-off fallback routing condition, versus dropped purchased/unlocked access derivation. Distinct.
11. F: close button touch target too small, versus title padding overlapping the close button. Distinct.
12. G: endpoint materialising the whole purchase set, versus which purchases are viewable. Distinct.

Net: 11 of 12 are distinct defects in one function; one (pair 9) is a real repost under the 0.20 text
bar. The per-PR target of 0.05 is not met as defined; 0.062 with the known miss counted.

## What else changed in the replay

- `fixed` fell from 245 to 167: a row is fixed only when absent and its file changed between the head
  it was last seen at and the current head; the rest stay open and count as still open.
- 33 notes went into existing threads instead of new roots: "Back at <sha7>" when a fixed row
  returned, and one severity line when an aliased finding's cited lines had changed.
- `roots_posted` fell by 31 with no round skipped: every removed root was a repost or a return.

go run ./cmd/publishreplay --alias-text-only --dumps <audit folder>/prs --sidecars <audit folder>/sidecars --offline --out textonly.json
